Anatomy
.popup > __icon + __content (__title + __message + __actions) + __dismiss
Modifiers
--success · --warning · --danger (icon color only)
Rules
  • Notification popups: role="status" + __dismiss. Confirmation popups: role="alertdialog" + __actions, no dismiss.
  • Icon matches the state: info-circle · circle-check · alert-triangle · alert-circle.
  • Buttons in __actions use --small; destructive confirmations that need full attention use .modal instead.
  • Max width 320px; the host page positions it (this guide shows it in-flow).

Tooltip

.tooltip

CSS-only label on hover/focus for icon buttons, truncated values, and “?” affordances. Text lives in the data-tip attribute.

Anatomy
.tooltip[data-tip="…"] on the trigger — the bubble is a ::after, no extra markup.
Modifiers
top (default) · --bottom · --right · --left
Rules
  • Short labels only (max-width 240px). Longer explanations belong in a __hint or a .popup.
  • Non-interactive triggers need tabindex="0" so keyboard users get the tip; icon-only triggers still need an aria-label.

Loading states

.spinner.skeleton

Loading states. Spinner = indeterminate action in progress; skeleton = content-shaped placeholder while data arrives.

Spinner
sizes mirror .icon: --sm 14 · default 18 · --lg 22 · arc = accent, or the button’s text color inside a .button
Skeleton
__line (+ --half / --third) · __block — stack them to sketch the loading layout
Rules
  • Spinner for actions (a click is being processed, disable the trigger); skeleton for regions (a card/table body is loading).
  • Standalone spinners need role="status" + aria-label; skeletons are aria-hidden.
  • Both stop animating under prefers-reduced-motion (global rule).

Progress bar

.progress

Determinate progress for imports, scans, and bulk operations. Distinct from .stepper --bar, which shows wizard position.

Elements
__head (__label + __value) · __track · __bar (width = inline style)
Modifiers
accent (default) · --success (complete) · --danger (failed / aborted)
Rules
  • Bar width is state, not design — the host page sets it as a custom property (style="--fill: 60%"), never a raw inline width — and mirrors it in aria-valuenow.
  • Unknown duration → use a .spinner instead; never animate a fake percentage.
