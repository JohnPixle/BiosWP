Anatomy
.list-table > __toolbar (__group + __count + __pagination) + __table (thead + tbody > __row + tfoot) + __toolbar--bottom
Row anatomy
__row > __check-cell + __cell (__primary + __actions > __action / __actions-sep) + __cell…
Row variants
default · --selected · --warning · --danger · --disabled
Rules
  • Quick actions are hidden until row :hover or :focus-within — keyboard users get them on tab.
  • Column headers repeat in tfoot, wp-list-table style; toolbar repeats below with bulk actions + pagination.
  • --selected pairs with a checked row checkbox; --disabled disables the checkbox and hides quick actions.
  • Danger quick actions still require a .modal confirmation.
  • In a design tool: the row is its own component with the five variants above; the table composes row instances.
  • For a titled screen, wrap in .card--flush + .list-table--flush: the card supplies the header, the table runs edge to edge (see example.html, list pattern).

Code block

.code-block

Read-only multi-line code display: shortcode examples, config samples, log excerpts. Display only — editing stays a field + monospace textarea (plugins mount a real editor).

add_filter( 'example_filter', function ( $value ) {
    return $value;
} );
Elements
__pre (pre > code) · __copy (optional, top-right; reuses .button --small)
Rules
  • Display only — no syntax highlighting (JS concern, out of scope like editors). One line + copy → .copy-field; editable code → .field + monospace textarea.
  • Long lines scroll horizontally; never wrap code.
  • Clipboard behavior is the host page's concern.
